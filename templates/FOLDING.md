# Fold one sheet into an eight page zine

You need `zine-print.pdf`, one sheet of A4 (or US Letter), scissors, and two minutes.

## Print it
- Landscape, one side only, colour.
- Scale: **Actual size** on A4. On US Letter choose **Fit to page**.
- Turn on **Background graphics** if your print box asks.

## The sheet
The top row prints upside down. That is on purpose: it lands the right way up once folded.

```
 +-----------+-----------+-----------+-----------+
 |           |           |           |           |
 |     5     |     4     |     3     |     2     |   <- top row, printed upside down
 | (upside   | (upside   | (upside   | (upside   |
 |   down)   |   down)   |   down)   |   down)   |
 |           |           |           |           |
 +- - - - - -+===========+===========+- - - - - -+   <- === CUT HERE (middle two panels only)
 |           |           |           |           |
 |     6     |     7     |     8     |     1     |   <- bottom row, upright
 |  page 6   |  page 7   |   back    |   cover   |
 |           |           |           |           |
 +-----------+-----------+-----------+-----------+
         fold lines: every edge between panels
```

On the PDF the cut is the solid pink line marked CUT. The dashed grey lines are the folds.

## Fold it
1. Printed side up. Fold the sheet in half top to bottom, long edges together. Crease hard. Unfold.
2. Fold it in half left to right, short edges together. Crease. Unfold, then fold each short edge in to meet that centre crease. Crease. Unfold flat. You can see eight panels.
3. Fold it in half left to right again. Starting at the folded edge, cut along the middle crease to the next crease and no further. That is the pink CUT line.
4. Unfold. Fold top to bottom again, long edges together, printed side out.
5. Hold the two short ends and push them towards each other. The cut opens into a diamond, then into a plus shape. Keep pushing until the pages fold flat into a little book.
6. Turn it so the cover (page 1) is on the front. Crease the spine. Done.

Hand it to someone.
