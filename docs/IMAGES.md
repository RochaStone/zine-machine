# Images

Every image on the README is made by `python3 scripts/make-readme-images.py` from the example zine in `examples/`, with the tool's own renderer. No photos, no people.

| File | What it is |
|---|---|
| `docs/img/hero.png` | the y2k-blog window "zine-machine.exe" holding the example cover and page 3, with the visitor counter and mood line |
| `docs/img/triptych.png` | the example cover in analog, cyberpunk and y2k-blog |
| `docs/img/stories.png` | five of the Instagram story frames, across the three looks |
| `docs/img/print-sheet.png` | the one-sheet print layout in analog |
| `docs/img/step-01.svg` to `step-05.svg` | pixel step badges for "Start here" |
| `docs/img/divider.svg` | the gold pixel divider between README sections |
| `docs/img/heart.svg` | the gold pixel heart |
